Client download

One package. Unpack it and play.

The download is a full client. You do not need a separate base install, and you do not need to hunt down data files. Unpack it wherever you like, run the patcher once, and it keeps itself current from then on.

Get the client Create a free account

Windows only for now. You need an account before you can log in.

Installing

Three steps, start to finish

Make your account

Do this first. The client will not let you in without one, and the same login works for the control panel.

Create account

Unpack the archive

Put it somewhere your antivirus and Windows are relaxed about. Avoid Program Files and avoid running it straight out of a synced cloud folder.

Run the patcher

It pulls the current game files and then hands you the play button. Every future update goes through the same window, so keep the shortcut.

If it misbehaves

Common snags

Antivirus flagged the patcher
Custom game patchers get false positives constantly because of how they rewrite files. Add the folder to your exclusions, or ask in the Discord first if you would rather double check.
The patcher will not start
Right click and run as administrator, and make sure the folder is not inside OneDrive, Dropbox or a similar synced directory. Those lock files while the patcher is writing them.
It patches but will not log in
Check that your account exists and that the server is actually up. If both look fine, post in the support channel on Discord with a screenshot of the error.
Can I run more than one client?
Yes. Vending and a second character are normal here, especially since there is no PvP to abuse it in.
